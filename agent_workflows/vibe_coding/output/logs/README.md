# Preserved run records

Execution, installation, validation, and session records previously loose in `output/paper/` are kept here. They record historical runs and may mention script paths from before the directory cleanup. Their contents have been preserved.

Current paper products are in [paper](../paper/README.md). Candidate-method results and their session record live under [exploratory](../../exploratory/README.md). New shell-captured run logs should be saved here; individual scripts continue to write their established data and result files.
