# Preliminary workflow archive

This archive holds earlier pairing utilities, exploratory LASSO variants, provisional meta-analysis and figure scripts, previous run reports, logs, model objects, and generated tables. The files were moved here on 2026-09-29 to keep `R/`, `config/`, and `output/` focused on the current paper workflow. They are preserved for provenance and are not called by `R/run_paper_workflow_agent_v1.R`.

The original human-written analysis and map scripts outside `agent_workflows/vibe_coding/` remain in their repository locations. Some archived scripts use their former paths and would need path updates before they could be rerun from this archive.
